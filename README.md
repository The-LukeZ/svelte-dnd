# svelte-dnd

Monorepo for [`@lukez/svelte-dnd`](packages/svelte-dnd/README.md), a Svelte 5 drag and drop library forked from [`svelte-dnd-action`](https://github.com/isaacHagoel/svelte-dnd-action).

The migration is in progress. See [MIGRATION_PLAN.md](MIGRATION_PLAN.md) for the stages.

## Development

```bash
pnpm install
pnpm build
pnpm test
```

Also: `pnpm lint`, `pnpm format`, `pnpm check:package`.
